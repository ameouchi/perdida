# La Gran Pérdida

Visualización interactiva sobre el éxodo poblacional y dinámicas de 70 centros urbanos en México.

## Descripción

Este proyecto analiza cómo se redistribuyó la población dentro de las ciudades mexicanas entre 1990 y 2020, mostrando el fenómeno de vaciamiento de las zonas centrales y expansión hacia las periferias.

## Tecnologías

- D3.js v7
- HTML5 / CSS3
- GeoJSON

## Estructura

- `index.html` - Archivo principal de la visualización
- `files/` - Directorio con archivos GeoJSON de las zonas metropolitanas
- `d3.v7.min.js` - Biblioteca D3.js

## Despliegue

Este proyecto está configurado para GitHub Pages. Para desplegarlo:

1. Sube todos los archivos a un repositorio de GitHub
2. Ve a Settings > Pages en tu repositorio
3. Selecciona la rama `main` (o `master`) como fuente
4. El sitio estará disponible en `https://[tu-usuario].github.io/[nombre-repositorio]/`

## Notas

- Asegúrate de que todos los archivos GeoJSON estén en la carpeta `files/`
- El archivo `.nojekyll` está incluido para evitar el procesamiento de Jekyll
